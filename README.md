# Astra Career 🚀

A modern career development and job assistance platform built to help users explore opportunities, improve skills, and manage their professional growth efficiently.

## 🌟 Features

- 🔐 User Authentication & Authorization
- 👤 User Profile Management
- 💼 Career & Job Exploration
- 📄 Resume / Portfolio Features
- 📱 Fully Responsive Design
- ⚡ Fast and Optimized Performance
- 🎨 Modern UI/UX
- 🔍 Search & Filter Functionalities


## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS / CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Tools & Services
- Git & GitHub
- VS Code
- API Integrations
